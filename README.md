# Global MapleStory Emulator
GMSE 是 MapleStory GMS 0.83 的一个汉化实现
## 1 开发帮助
### 1.1 提交规范
- **新增** 增加新功能或提交新的资源文件
- **更新** 代码重构或者更新工具版本等
- **修复** 修复bug
- **文档** 提交新文档或更新旧文档
- **汉化** 批量提交汉化内容
- **移除** 删除任何东西
