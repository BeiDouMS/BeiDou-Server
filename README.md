# Global MapleStory Emulator
GMSE 是 MapleStory GMS 0.83 的一个汉化实现

## 和北斗的区别
北斗忠于原版，而GMSE期望在原版的基础上加入一些新的元素玩法等。这是创建本项目的主要原因。

北斗支持多语言，GMSE不支持。多语言会增加开发工作量减缓开发进度，且现在人手不足，加上有其他一些潜在的问题，
解决起来需要不少时间来思考，因此GMSE短时间内不会支持多语言。

## 特殊改动
### 倍率
- 经验倍率：1x
- 金币倍率：1x
- 物品爆率：1x
- Boss爆率 1x
- 任务倍率：5x
- 新手限制：等级<=10级的新手职业，经验倍率固定为1倍
- 等级加成：**刷怪**获得额外 Lv * 0.01 倍经验
- 等级冲刺：**刷怪**获得额外 (80 - Lv) * 0.1 倍经验（等级低于80级生效）

这种经验倍率设置旨在帮助玩家快速渡过新手阶段，后期又不会升级过慢，整体的刷怪经验倍率成曲线动态调整，
从一转开始逐渐降低，直到80级后再慢慢升高。

刷怪倍率举例（不含双倍卡活动等）
- 新手： 1 倍
- 10级： 1 x (1 + 10 * 0.01) x \[1 + (80 - 10) x 0.1\] = 8.8 倍
- 50级： 1 x (1 + 50 * 0.01) x \[1 + (80 - 50) x 0.1\] = 4.5 倍
- 80级： 1 x (1 + 80 * 0.01) = 1.8 倍
- 100级：1 x (1 + 100 * 0.01) = 2 倍
