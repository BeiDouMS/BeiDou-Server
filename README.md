## 3 特殊改动
### 3.1 倍率
- 经验倍率：1x
- 金币倍率：1x
- 物品爆率：1x
- Boss爆率：1x
- 任务倍率：5x
- 新手限制：等级<=10级的**新手职业**，经验倍率固定为1倍
- 等级加成：**刷怪**获得额外 Lv * 0.01 倍经验
- 等级冲刺：**刷怪**获得额外 (80 - Lv) * 0.1 倍经验（等级低于80级生效）

这种经验倍率设置旨在帮助玩家快速渡过新手阶段，后期又不会升级过慢，整体的刷怪经验倍率成曲线动态调整，经验倍率从一转后的8.8倍逐渐降低，直到80级后再慢慢升高。

刷怪倍率举例（双倍卡等加成另外计算）
- 新手： 1 倍
- 10级： 1 x (1 + 10 * 0.01) x \[1 + (80 - 10) x 0.1\] = 8.8 倍
- 50级： 1 x (1 + 50 * 0.01) x \[1 + (80 - 50) x 0.1\] = 4.5 倍
- 80级： 1 x (1 + 80 * 0.01) = 1.8 倍
- 100级：1 x (1 + 100 * 0.01) = 2 倍
