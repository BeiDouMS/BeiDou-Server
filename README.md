# Global MapleStory Emulator
GMSE 是 MapleStory GMS 0.83 的一个汉化实现

## 和北斗的区别
北斗忠于原版，而GMSE期望在原版的基础上加入一些新的元素玩法等。这是创建本项目的主要原因。

北斗支持多语言，GMSE不支持。多语言会增加开发工作量减缓开发进度，且现在人手不足，加上有其他一些潜在的问题，
解决起来需要不少时间来思考，因此GMSE短时间内不会支持多语言。
